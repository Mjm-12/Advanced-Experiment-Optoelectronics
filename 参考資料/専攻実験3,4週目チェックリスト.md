## 測定方法
電源電圧やオフセット電圧など直流電圧を測りたい→DC電圧の測定
信号の周波数や電圧をざっと知りたい→AC信号の測定
信号の周波数や歪みなどを詳しく知りたい→FFT用信号の記録＋FFT解析（PC）

> [!tips]
> 電圧や周波数などの測定データを記録するときは、測定条件（どんなパラメータで、どこをどんな方法で測定したか）も併せて記録しよう！
>>[!example] パラメータの例
>> - 可変抵抗の回転角度（左に回しきった時0%、右に回しきった時100%として、RV101: 30%、RV102: 50%など）
> >- 電源電圧（主にTP101, 201, 301, 401など）
> >- スイッチの切り替え方向（ON、OFF、ニュートラル、○○側、など伝わる形で）
> >- 印加した信号の種類、振幅、周波数（例：1 kHz サイン波、20 mV<sub>p-p</sub>）
> >- FRA時の入力信号の振幅
> >- D303〜306に接続したダイオードの種類、型番
### DC電圧の測定
#### 方法1：オシロスコープを使う
1. プローブのカップリングをDCにする（測定に使うプローブのChキー→Coupling: DC）。
2. Meas→Type: Averageを選択し、表示する。
3. 測定したいテストポイントに接続し、電圧範囲やオフセットを調節（信号が上下にはみ出ていたり、電圧範囲が広すぎると誤った値が表示される）。
   また、10ms/divなど、ある程度表示時間の範囲を広く取る（低周波信号の影響を取り除くため。）
#### 方法2：デジタルマルチメータを使う
1. Mode: DCVを選択。
2. 測定したいテストポイントに接続。
### AC信号の測定
1. プローブのカップリングをACにする（測定に使うプローブのChキー→Coupling: AC）。
2. Meas→Type: Freqやpk-pkなどを選択し、表示する。最大5個まで選択可能。
3. 測定したいテストポイントに接続し、電圧範囲や時間範囲、オフセットを調節する。必ず上下にはみ出さず1周期以上表示されるよう範囲を調節する。


<div style="page-break-after: always;"></div>

### FFT用信号の記録
重要：*FFT解析したい信号を測定するときは**Ch1**を使うこと！*
1. プローブのカップリングをDCにする（測定に使うプローブのChキー→Coupling: DC）。
2. 電圧範囲やオフセットを調整する。必ず上下にはみ出さないようにする。
3. 時間軸を100ms/divなど、できるだけ長く調整する。信号が見えにくくなってもOK。
4. Save/Recallから保存する。その際、フォーマットはcsvを選択し、記録点数は最大の50,000を選ぶ。

## 回路A-B
### 測定
- [ ] 回路A-Bを接続し、TP101, 102, 201のDC電圧を測定する。
- [ ] TP104, TP105にそれぞれプローブを接続し、RV102を回した時の変化を観察する。RV102で調整出来る周波数帯を調べる。
- [ ] RV102,103を100%(最大まで右回し)、SW101を1番ピン側（矩形波が出力されるよう選択）、RV201を任意の大きさまで回した状態で音が出るようにRV101を調整し、そのときのTP103のDC電圧を測定する。
- [ ] SW101を三角波側へ切り替え、TP106, 107, 202, 203でそれぞれ信号を記録し、FFT解析する。矩形波との違いは？（TP104,は矩形波、TP105は三角波が常に出力されているため参考にするとよい）
- [ ] SW101をニュートラル（中立：どちらにも繋がっていない状態）にして、TP106からオシロスコープのWave Generator機能を使って、任意の周波数のサイン波を印加しながら、TP106, 107, 202, 203でそれぞれ信号を記録し、FFT解析する。
- [ ] RV101を調整して、音が出るときと出ない時の違いを考えよう。RV102を0%（最大まで左回し）の状態で、RV101を変えてみて、音が出るとき・出ない時それぞれのTP103のDC電圧TP107,202の波形を比較する（FFTは必要に応じて）。
    また、PLT133の発光状況を目視で観察してみよう。
- [ ] 回路A-Bの接続を外し、回路Bの周波数特性を測定する。資料のFRA（周波数応答解析）項を参考にしながら、TP202-TP203間でFRAを実行する。測定する周波数範囲は10Hz~30kHz程度。
- [ ] TP202からオシロスコープのWave Generator機能を使って、任意の周波数のサイン波を印加する。少しずつ周波数を上げていき、可聴帯域を特定する。
- [ ] TP202から任意の波形（サイン波・矩形波・三角波など）、周波数の信号を印加しながら、TP203の波形やFFT結果と聴感を評価してみよう。（例：矩形波はどんな感じの音？FFTすると、どんな周波数成分が含まれている？）
> [!hint]
> 聴感とFFT結果から求められる歪み率や倍音（Harmonic）成分に注目しよう！

### 考察

- [ ] FRA結果を踏まえて、回路Bはスピーカーアンプとして十分な性能か？（人間の可聴帯域と周波数応答の凸凹から総合的に評価してみよう）

## 回路C-D
### 測定
- [ ] 回路C-Dを接続し、TP301, 302, 401のDC電圧を測定する。
- [ ] TP307にプローブを接続する。次に、TP304からオシロスコープのWave Generator機能を使って1kHzのサイン波を印加しながら、TP307で綺麗なサイン波が出力されるよう、Wave Genの振幅やRV301, 302を調整し、記録する。
- [ ] 印加するサイン波の周波数を徐々に上げていき、人間の可聴帯域を特定する。
- [ ] 回路C-D、C単体、D単体の周波数特性を測定する。資料のFRA（周波数応答解析）項を参考にしながら、
      - TP304-405間（C-D）
      - TP304-307間（C単体）
      - TP402-409間（D単体）
    でFRAを実行する。測定する周波数範囲は10Hz~可聴帯域をやや上回る程度で、振幅は歪まないように適宜調整しよう。
- [ ] TP304から任意の波形（サイン波・矩形波・三角波など）、周波数の信号を印加しながら、TP405の波形やFFT結果と聴感を評価してみよう。
> [!hint]
> 聴感とFFT結果から求められる歪み率や倍音（Harmonic）成分に注目しよう！
- [ ] 440Hz程度のサイン波を印加しながら、徐々にRV301を右に回すと聴感やTP307, 405の波形やFFT結果はどうなるか？
- [ ] D303, 304に適当な色のLEDを互い違いに接続し、SW302をオン・オフしたときの聴感やTP307, 405の波形やFFT結果を比較してみよう（そのとき、違いが出るようにRV301や印加する信号の振幅を調整しよう）。
- [ ] 接続するLEDを片側だけにしてみたり、LEDの色を変えたり、シリコンダイオード（1N4148）を繋いで同様の測定をしてみよう。
- [ ] D305, 306に適当なダイオードを繋いだとき、D303, 304との違いはあるだろうか？

### 回路Aの低周波発振器（LFO）について
U103周辺で構成される回路は低周波発振器（LFO: Low Frequency Oscillator）と呼ばれ、シンセサイザーやアナログコーラスエフェクターなど音楽分野で一般的に用いられる回路です。発振周波数の計算方法は以下の文献で言及されています。

>[!quote] [Ron Mancini "Op Amps For Everyone" A-44 (2002.8)](https://web.mit.edu/6.101/www/reference/op_amps_everyone.pdf#page=403.20)
>A.5.8Triangle Oscillator
>  
>The triangle oscillator produces triangle waves and square waves. The op amp functions as an integrator. When the output voltage of the comparator is low, the output of the op amp charges C until the output voltage exceeds the hysteresis voltage set by $R_1$ and $R_F$ and the reference voltage ($V_{CC}/2$). At this point, the comparator output switches to a high state and the op amp integrates the voltage in a negative direction.
>
>The triangle wave (op amp output voltage swing) is given in Equation A–49.  
>The frequency of oscillation is given in Equation A–50.
>
>Equation A–49:
>$$
V_{OUT} = \frac{V_{CC}}{2} \pm \frac{V_{CC} R_1}{2 R_F}
>$$
>Equation A–50:
>$$
 f = \frac{R_F}{4 C R R_1} 
 >$$
 >The op amp reference voltage can be adjusted to equalize the triangle rise and fall times.
 >![[専攻実験3,4週目チェックリスト-1.png]]
 >
 >---
 >【日本語訳】
 >>A.5.8 Triangle Oscillator  
>
>三角波発振器は、三角波および方形波を生成します。オペアンプは積分器として機能します。コンパレータの出力電圧が低いとき、オペアンプの出力はコンデンサCを充電し、出力電圧が$R_1$と$R_F$で設定されたヒステリシス電圧および基準電圧（$V_{CC}/2$）を超えるまで増加します。この時点で、コンパレータの出力は高状態に切り替わり、オペアンプは電圧を負方向に積分します。
>
>三角波（オペアンプの出力電圧スイング）は式A–49で示されます。  
>発振周波数は式A–50で示されます。
>
>Equation A–49:  
>$$
V_{OUT} = \frac{V_{CC}}{2} \pm \frac{V_{CC} R_1}{2 R_F}
>$$
>Equation A–50:  
>$$
f = \frac{R_F}{4 C R R_1}
>$$
>オペアンプの基準電圧は、三角波の立ち上がり時間と立ち下がり時間を等しくするように調整できます。
